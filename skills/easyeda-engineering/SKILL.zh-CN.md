# EasyEDA 工程设计

产出易读、电气正确、物理可实现的 EasyEDA 设计，并依据设计数据而不是截图完成验证。本技能提供工程工作流和签核门槛；需要实时操作 EasyEDA 时，使用 `easyeda-api` 中已有文档的调用。

本技能是自包含的，离开本仓库后也必须可用。仓库存在 `AGENTS.md` 时，将其作为本地覆盖规则，但不得假定用户或其他项目同时具备本工作区的规则。

本技能综合了 `easyeda-pro-claude-skill` 和 `easyeda-agent`，但不将任一项目的 CLI、daemon 或 connector 作为依赖。维护本技能或解决规则冲突时，读取 [references/upstream-integration.zh-CN.md](references/upstream-integration.zh-CN.md)。

## 任务路由

- 原理图绘制、整理或视觉重构：读取 [references/schematic-style.zh-CN.md](references/schematic-style.zh-CN.md)。
- 连接器、排针、收发器、DTE/DCE 接线、低有效控制或替代器件：读取 [references/interface-review.zh-CN.md](references/interface-review.zh-CN.md)。
- PCB 布局、布线、铜皮、机械审查或板级签核：读取 [references/pcb-engineering.zh-CN.md](references/pcb-engineering.zh-CN.md)。
- 任何实时编辑、交接、审计或签核：读取 [references/verification-loop.zh-CN.md](references/verification-loop.zh-CN.md)。
- 只读审查时只检查并报告；除非用户同时要求修改，否则不要变更设计。

## 项目范围

- 在读取或写入设计数据前，根据仓库指令、工作区结构或已选 EasyEDA 项目确定当前项目边界。
- 如果工作区规定每个二级目录都是独立项目，只选择其中一个目录，绝不跨兄弟项目混用、移动或修改设计数据。
- 目标仍不明确时，在任何修改前停止并请用户指定项目。
- 项目本地规则可以收紧或替换本技能的默认绘图几何和约定；否则使用 `schematic-style.zh-CN.md` 与 `pcb-engineering.zh-CN.md` 中的自包含默认值。

## 工程不变量

- 接触项目设计数据前确认唯一目标项目边界，绝不跨项目混用数据。
- 修改前确认 bridge 健康状态、活动窗口、项目、文档及文档类型。
- 先检查后修改。读取与任务相关的现有元件、图元、网络、规则和文档几何。
- 保留用户改动与设计意图，只做满足请求所需的最小完整修改。
- 放置、同步、切换页面或重新加载后，不要相信计划中的位号、图元 ID、引脚坐标、焊盘编号或几何；必须回读 EasyEDA 实际创建的内容。
- 将导出的原理图网表视为原理图连接关系真值。将 PCB DRC、焊盘网络归属、已布线/未布线连接、几何回读和重建后的铜皮状态视为 PCB 真值。截图和单纯的 API 成功响应都不能作为证明。
- 使用 `easyeda-api` 中已有文档的 API 签名与枚举；不得猜测参数、单位、层 ID 或返回结构。
- 使用小批量、可观察的修改。如果写入超时或结果不确定，重试前先检查，避免创建重复或冲突的图元。
- 在有意义且经过验证的检查点保存，然后确认保存状态能够持续存在。
- 清空页面、替换整块 PCB、删除布线、修改层叠或批量删除等破坏性或明显扩大范围的操作，必须在执行前取得明确授权。

## 工作流

1. 确认项目范围、bridge 健康状态、活动窗口、项目、文档和文档类型。
2. 捕获任务范围内的基线：相关器件与封装、引脚/焊盘到网络映射、NC 状态、几何、规则、DRC/检查结果和当前产物。
3. 重述期望的电气和物理结果。接线或批准封装前，为外部接口建立明确的引脚表。
4. 围绕信号流、功能分组、机械约束、布线通道和仓库约定规划修改。
5. 通过已有文档的 API 应用一个完整批次，随后立即回读受影响的图元和实际 ID。
6. 执行领域门槛：原理图工作比较导出网表；PCB 工作检查连接、几何、铜皮和 DRC。
7. 继续前解决意外的网络合并或拆分、引脚或焊盘重映射、残留、碰撞、间距错误或陈旧读数。
8. 保存并重新读取关键状态，报告已验证结果、剩余警告、有意保留的例外和未检查项目。

## 停止条件

- 不得猜测数据手册变体、连接器观察方向、符号引脚、封装焊盘、层规则、板框或机械要求。
- 活动文档变化或 bridge 断开时，停止实时编辑并重新建立上下文。
- 编辑后的原理图网表或 PCB 连接结果与意图冲突时，不得继续或宣称完成。
- 替代器件改变外围参数、控制接线、封装、热要求或布局约束时，将其视为设计变体，而不是只替换芯片。
- 读数疑似陈旧时，保存、重新建立活动文档并执行一次全新读取；不得进入盲目的重新加载或重试循环。
