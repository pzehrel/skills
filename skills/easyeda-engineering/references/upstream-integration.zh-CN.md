# 上游集成说明

维护本技能或解决本地与上游 EasyEDA 工作流冲突时，读取本文件。

## 已审查的来源

- [`v0id-byte/easyeda-pro-claude-skill`](https://github.com/v0id-byte/easyeda-pro-claude-skill) 的 `SKILL.md`，MIT 许可证。
- [`zhoushoujianwork/easyeda-agent`](https://github.com/zhoushoujianwork/easyeda-agent) 的主技能及相关原理图工作流、接线、布局和自动化参考资料，MIT 许可证。

本技能转述这些项目中的工程实践，不复制或依赖它们的 connector、daemon、CLI、脚本、内置模块库或本仓库的 `AGENTS.md`；本地指令是可选覆盖，而不是隐藏依赖。

## 采用的实践

- 修改前验证健康状态、窗口、项目、文档和文档类型。
- 先检查后修改；使用小批量可观察操作、回读和有意义的保存检查点。
- 将全新导出的网表视为原理图真值，判断 PCB 时使用 DRC 与数据回读，而不是截图。
- 将基线与编辑后状态比较，以发现看似连接但实际未连接的情况、静默网络合并或拆分、引脚功能变化、陈旧几何和持久化失败。
- 不要盲目重试结果不确定的写入。
- 重组已接线原理图前，保留权威的引脚到网络映射和 NC 映射。
- 删除、重命名或替换器件后，清理陈旧短线、孤立端口、悬空导线和其他碎片。
- 需要时在布线后重建铜皮，并从全新数据验证已保存布线，而不是依赖单纯的成功响应。

## 有意保留的本地差异

- 官方 `easyeda-api` bridge 仍是操作层；不依赖 `easyeda-agent` 的 CLI、daemon 和 connector。
- 除非仓库 `AGENTS.md` 要求，否则分页、区域边框和模块说明只是可选的可读性工具。
- 本地原理图样式优先使用短而直接的导线，不会默认将每个引脚扇出到标签。
- 电源和地标志使用真实的非零短线。只有全新导出的网表证明当前运行时中的连接时，才接受直接附着网络端口。
- 详细 PCB 约束来自当前项目、数据手册、机械要求和实时设计规则；上游数值示例不是通用默认值。

## 优先级

按以下顺序应用规则：

1. 用户对当前任务的指令。
2. 仓库 `AGENTS.md` 和项目本地约束。
3. 本技能的工程不变量和验证门槛。
4. 仅在符合当前 API 与运行时行为时采用上游观察结果。

来源冲突时，运行最小且安全的实时探测，并依据全新设计数据、连接关系和 DRC 证据判断，而不是截图。
