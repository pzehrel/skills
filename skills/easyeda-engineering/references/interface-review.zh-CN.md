# 接口与引脚审查

在接线或批准连接器、排针、收发器、低有效握手信号或替代 IC 前，读取本参考文档。

## 先建立引脚表

为每个外部连接器记录：

| 字段 | 含义 |
| --- | --- |
| 物理引脚 | 目标设备手册定义的编号 |
| 设备信号 | 手册中的准确名称 |
| 方向 | 从设备视角定义的输入或输出 |
| 源端与接收端 | 哪个器件驱动该线路，哪个器件接收该线路 |
| 原理图端点 | 符号位号及引脚名称/编号 |
| 封装焊盘 | PCB 物理焊盘编号 |
| 网络名称 | 唯一预期的原理图网络名称 |
| 处置方式 | 已连接、共享、上拉/下拉或有意 NC |
| 验证 | 最新网表证据和 PCB 焊盘到网络的证据 |

在每个已用引脚都有明确记录前，不得接线或批准连接器。

## 连接器方向

- 确认手册展示的是插合面、线缆侧、元件侧还是焊接侧。
- 分别验证 1 脚、行编号、奇偶列、防呆、缺针、镜像和连接器旋转。
- 比较符号引脚编号与封装焊盘编号；不得根据屏幕位置推断任一编号。
- 放置、替换或完成原理图到 PCB 同步后，回读实际的符号引脚、封装焊盘、网络归属和位号。

## 方向敏感的串行接口

- 映射信号前，确定每个端点是 DTE 还是 DCE。
- 将驱动器输出连接到接收器输入。DTE 到 DTE 或零调制解调器接线中，同名信号并不自动表示连接正确。
- 将低有效后缀视为逻辑语义，而不是装饰。
- 一个物理信号连接多个接收器输入时，使用唯一明确的网络名并列出每个成员引脚。
- 两个端点都只提供输入且没有器件驱动线路时，除非设计明确要求固定电平，否则保持 NC。

## 替代器件

验证符号功能、封装焊盘、电源与逻辑阈值、外围参数、使能或关断行为、裸露焊盘要求、数据速率、负载、ESD 假设、热需求和 PCB 布局约束。

任一项目发生变化时，记录替代装配方案或电路变体。替换后，证明目标网络增加了预期的新引脚或焊盘，并且旧网络不再包含它。
