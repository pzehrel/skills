# 原理图工程样式

绘制、重组或评估 EasyEDA 原理图时，读取本参考文档。以下是可移植默认值；明确的项目规则可以覆盖它们。

## 默认绘图边框

项目没有明确图纸规则时，使用以下默认逻辑绘图边界：

| 位置 | 坐标 `(x, y)` |
| --- | --- |
| 左上 | `(0.1, 8.15)` |
| 左下 | `(0.1, 0.1)` |
| 右上 | `(11.6, 8.15)` |
| 右下 | `(11.6, 0.1)` |

所有原理图内容必须位于 `0.1 ≤ x ≤ 11.6` 且 `0.1 ≤ y ≤ 8.15` 的范围内。

默认将右下角的注释/标题区域保留为严格禁画区：

- 左上角：`(4.6, 1.9)`
- 右下角：`(11.6, 0.1)`
- 包含边界的区域：`4.6 ≤ x ≤ 11.6` 且 `0.1 ≤ y ≤ 1.9`

不得在该区域放置元件、导线、标签、文字或其他原理图图元。如果活动图纸使用不同坐标系或标题栏几何，先推导实际边界，再应用同样的两个不变量：保持在图纸内，并位于注释区域外。

## 布局

- 优先满足人工审查、故障定位和真实制造需求，而不只是形式上的电气连接。
- 除非电路天然需要其他方向，否则主信号路径从左到右排列，电源或控制依赖从上到下排列。
- 按功能分组器件：外部接口、保护、电源、控制器、逻辑电平、物理层和输出接口。
- 将每个 IC 的去耦、电荷泵、振荡器、复位和模式设置器件放在该 IC 旁边。
- 将板边连接器放在其功能模块边缘，并调整方向以便清晰阅读和后续 PCB 布局。
- 将相关器件对齐到一致网格，留出足够空白，使数值、位号和引脚名称保持可读。
- 所有图元必须位于仓库定义的图纸边界内和标题栏禁画区外。仅在没有本地边界定义时使用实时图纸几何。
- 对已接线图纸，在可用 API 能保持局部导线和标记的情况下，将功能组整体移动；否则小步移动，并在每批操作后验证引脚到网络的拓扑。
- 只有功能框或说明能实质改善导航时才添加。除非仓库规则要求，否则紧凑的单用途图纸不强制添加。
- 没有具体理由时，不要反转阅读方向，也不要让同一信号路径来回折返。

## 导线与标签

- 模块内关系明确时，使用短而直接的导线。
- 仅当导线需要跨越较长距离、离开模块或标签能提高可读性时使用网络标签。
- 默认不要把每个引脚都扇出到标签。
- 导线使用水平和垂直路径。端点不对齐时使用 L 形路径，并让布线通道避开无关引脚。
- 不要穿过无关引脚绘线；EasyEDA 可能在那里分割导线并形成电气连接。
- 对多引脚局部网络，优先使用锚定到引脚的链式连接或名称明确的端口。不要依赖未锚定的自由空间星形结点。
- 绝不创建零长度导线。电源与地标志必须位于真实的非零短线末端，而不是直接放在裸引脚上。
- 一个物理网络只使用一个名称。如果两个功能有意连接，使用一个组合名称，例如 `DSR_DCD`。
- 在整个项目中保持低有效表示法一致。
- 重命名、删除或替换后，移除悬空短线、重复标记、孤立端口、旧网络残留和导线碎片。
- 使用一致的电源和地符号，不要使用含义相同的电源轨别名。
- 按电气域和功能命名网络，例如 `USB_D+`、`TTL_TX` 和 `COM_NSIN`。网络出现的每一处都必须保持拼写、大小写、前缀、后缀和低有效标记一致。
- 不要用孤立标签伪装未使用引脚已经处理；应使用明确的 NC 标记。

## 元件与标注

- 选择实际可采购的器件和 PCB 预期使用的准确封装。
- 每类标准位号从 1 开始连续编号。仓库规则允许时，可以使用功能性连接器名称。
- 将放置后返回的位号视为权威值；当其他页面已经使用计划位号时，EasyEDA 可能重新编号。
- 没有电气或布局理由时，不要保留重复无源器件。
- 保持数值、器件名称、位号和重要引脚名称可见且互不重叠。
- 在有意不使用的引脚上放置明确 NC 标记。
- 按信号流一致地调整每个 IC 的方向：输入朝向源端，输出朝向目标端。
- 让去耦、电荷泵、晶振、复位和模式设置网络在视觉上与所属 IC 关联，并在局部连接。
- 将连接器放在功能边界，在可能的情况下使其方向反映真实插合方向和预期 PCB 位置。
- 一致地对齐重复外围电路。除非电路或物理实现需要，否则移除功能冗余的并联器件。
- 添加、删除或替换器件后，检查每类位号是否重复、跳号或继承了无意义的大编号；需要时在交接前重新标注。
- 视觉上方便的符号或封装不能替代真实连接器、封装、机械引脚或缺针模式。

## 可读性审查

工程师应无需搜索整张图纸，就能识别电源路径、主要接收/发送路径、跨模块信号、模式控制和未使用连接器引脚。如果必须匹配大量分散标签才能做到，应在签核前重组图纸。

画布只用于视觉审查。任何移动电气图元的重构完成后，重新导出并比较网表。

## 原理图完成门槛

- 运行 DRC，解决或明确解释每个错误和警告。
- 导出或读取实际生成的网表，检查电源、接收/发送方向、握手信号、合并网络及每个外部连接器引脚。
- 对关键接口，将最终的每一行 `designator.pin → net` 与设备手册比较。
- 同步到 PCB 前，确认每个需要制造的器件都使用预期封装，并正确处理裸露焊盘、机械引脚、屏蔽引脚和缺针位置。
- 删除、重命名或重新标注后，重复网表检查、清理残留、保存并验证持久化状态。
